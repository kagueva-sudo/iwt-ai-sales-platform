# Learning & тест-наборы IWT

Три слоя — не смешивать:

| Файл | Зачем | В system prompt AI? |
|------|--------|---------------------|
| `../faq.json` + доменные `../delivery.json`, `payment.json`, … | Боевая Knowledge Base (поиск бота) | Нет, только найденные куски |
| `../faq_phrases.json` | Много формулировок тех же тем → лучше ловит «живые» фразы | Нет |
| `customer_qa.jsonl` | Банк Q&A для людей, тестов и будущего RAG | Нет |
| `evaluation_dataset.jsonl` | Автопроверка: intent / handoff / не выдумывать цену | Нет |

Правила:

- Цену и наличие **не** пишем как готовый FAQ-ответ с цифрами — только «смотрите сайт / менеджер / live-каталог».
- Жалобы, скидки, КП, индивидуальные сроки — в evaluation с `expected_handoff: true`.
- Новые реальные фразы клиентов: сначала в `customer_qa.jsonl`, при стабильном ответе — тег/фраза в KB.
